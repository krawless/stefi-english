# STEFI WORLD – varianta „Roblox”

Joc 3D pe laptop (tastatură + mouse). Lecțiile sunt niveluri (obby-uri blânde). Un nivel se deblochează după ce îl termini pe cel dinainte.

## Motor
- [x] Lume 3D în stil Roblox: plastic, platforme cu „studs”, copaci pătrățoși, cer cu nori
- [x] Mișcare: WASD / săgeți, Space = săritură, mouse (drag) = cameră, rotița = zoom
- [x] Camera din spate, care urmărește jucătorul ușor
- [x] Fizică simplă: gravitație, coliziuni, urcă singur treptele mici
- [x] Căderea în apă îl readuce la ultimul checkpoint, fără penalizări
- [x] Checkpoint-uri (steaguri), monede care se rotesc, porți care se deschid
- [x] Plăci-răspuns: calci pe placa corectă și se deschide poarta
- [x] Etichete cu nume și bule de chat deasupra personajelor
- [x] Cer care se schimbă (dimineață / zi / seară / noapte)

## Personaje
- [x] Avatar pătrățos R6 (cap-cub cu față :), trunchi, mâini, picioare) cu animații de mers, săritură și salut
- [x] Avatarul lui Stefi (implicit: băiat, culorile clasice Roblox)
- [x] NPC-uri: Chen, Ella, Mark, Asha în stil pătrățos
- [x] Accesorii: pălării, aripi, aură, animal de companie care te urmează

## Lobby (hub)
- [x] Spawn, 4 portaluri (Lesson 1–4) cu lacăt până le deblochezi
- [x] Magazin (cumperi accesorii cu monede)
- [x] Oglinda / garderoba (schimbi culori, păr, nume)
- [x] Monede de strâns prin lobby

## Nivelul 1 – HELLO, EVERYONE!
- [x] Insula 1: atinge fiecare prieten, iar el se prezintă (4/4 deschide poarta)
- [x] Insula 2: „Where is Ella?”, mergi la prietenul corect (3 runde)
- [x] Insula 3: „Say your name!”, urci pe scenă și spui „Hi! My name is Stefi.”
- [x] Trofeu, apoi nivel terminat

## Nivelul 2 – GREETINGS
- [x] Insule cu cer diferit: dimineață, după-amiază, seară, noapte
- [x] Pe fiecare, Mark te salută, tu calci pe salutul corect (3 plăci)
- [x] Insula „Goodbye”: Mark pleacă acasă
- [x] Trofeu

## Nivelul 3 – THE ALPHABET
- [x] Drumuri făcute din cuburi-litere A–Z (spune litera când sari pe ea)
- [x] Insula „Which letter?”: imagine și 3 plăci-litere (3 runde, cuvântul doar la 🔊)
- [x] Insula „Find the letter M!”: 4 plăci-litere (3 runde)
- [x] Insula „Spell your name”: calci literele numelui în ordine
- [x] Trofeu

## Nivelul 4 – COLOURS
- [x] Insula „Jump on RED!”: 9 plăci colorate (3 runde)
- [x] Insula „Paint it!”: obiect gri și 3 găleți de vopsea (3 runde)
- [x] Podul de culori: „Walk on GREEN only!” (celelalte plăci cad)
- [x] Trofeu și ecranul final „YOU WIN!”
